**An easy start.** WebDavSync now sets itself up: unpack, run `WebDavSync.exe`, and a short wizard connects your
cloud and your folder.

### New

- **Setup wizard** on the first start (and *Add a folder…* in the tray menu):
  1. connect your cloud — Mail.ru Cloud or any WebDAV server, with an immediate connection check;
  2. choose the folders — browse the cloud's folders; the wizard explains what will happen and takes over the old
     Mail.ru Cloud app's folder or the state of an earlier WebDavSync setup, so nothing is downloaded again;
  3. choose how careful it should be, and whether to start with Windows.
- **One copy at a time**: starting the app again only points you to the running one.
- **Sharp on high-DPI screens**: all windows scale with Windows display scaling.
- The download now contains only the app (`WebDavSync.exe`); the command-line tool is built from source.

### Upgrading from 0.1.0

Exit the running app, replace `WebDavSync.exe`, start it again. If you set up the folder with the command line in
0.1.0, run the wizard and choose the same folder: its sync state is reused.

### Коротко по-русски

Лёгкий старт: распакуйте архив и запустите `WebDavSync.exe` — мастер подключит облако и папку, проверит пароль,
подхватит папку старого приложения Облака Mail.ru или прежнюю настройку WebDavSync без повторного скачивания.
Одновременно работает только одна копия программы. В архиве теперь только приложение.

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
