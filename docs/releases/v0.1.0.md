First public release of **WebDavSync** — careful two-way sync between a Windows folder and a WebDAV cloud
(built for and tested with Mail.ru Cloud).

### Download

`WebDavSync-0.1.0-win-x64.zip` below: unpack into a writable folder and run `WebDavSync.exe`.
Requires Windows 10/11 x64 and the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).
Getting started: [README](https://github.com/gray0072/webdav-sync#quick-start)
([Русский](https://github.com/gray0072/webdav-sync/blob/main/README_ru.md#быстрый-старт),
[Svenska](https://github.com/gray0072/webdav-sync/blob/main/README_sv.md#kom-igång)).

### What's inside

- **Two-way sync** with a three-way merge (local · cloud · base): edits, deletions, moves and renames on both sides;
  conflicts keep both versions.
- **Safety guards**: no deletions on the first sync, deletions only of unchanged items, Recycle Bin for local
  deletes, mass-delete guard in every mode, root markers that stop a pair whose folder went missing.
- **Tray app**: status icon, sync now, pause, approvals window, folder selection, settings, CPU and I/O limits,
  start with Windows.
- **CLI `wds`**: probe, pairs, plan, sync, held list, auto-approve rules, folder selection, stored passwords.
- **Efficient cycles**: local changes re-list only the touched cloud folders; full cloud checks on a chosen schedule;
  parallel listings; start-up trusts a fresh state.
- **Large files**: resumable downloads (`Range`), retries of dropped transfers.
- **Mail.ru**: imports the old client's `.cloud.db`; exact comparisons via Mail.ru content hashes.
- **Portable**: two single-file executables; passwords in the Windows Credential Manager.

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
