**Progress in percent, settings kept on a manual update.**

### Improved

- **Scan progress in percent**: while checking for changes the tray shows `Crawling remote: 42%` and
  `Scanning local: 67%, hashed …` instead of growing folder counts. The total is estimated from the last sync, so the
  value stops at 99 % until the scan ends; the very first sync still shows counts.
- **Settings follow a new copy**: a new version unpacked into another folder takes over the settings of the copy that
  ran last on its first start and moves *Start with Windows* to itself. Passwords and the sync state are not in the
  app folder, so nothing has to be set up again. Updates installed from the tray menu keep everything as before.

### Upgrading from 0.3.0

Use *Update to 0.3.1…* in the tray menu, or replace `WebDavSync.exe` in the same folder.

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
