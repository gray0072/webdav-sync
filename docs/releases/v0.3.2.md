**A responsive tray menu.** The tray icon now opens its menu at once, also while a sync is running.

### Fixed

- **Slow right-click on the tray icon**: *Low priority* used Windows background mode for the whole app, which also
  slowed down the tray menu and let Windows take most of the app's memory away, so every right-click first had to
  load the menu back from disk at the lowest disk priority. Now only the sync work runs at low priority: the app is
  below normal, the tray menu stays at normal priority, and hashing, uploads and downloads use the lowest disk
  priority per file. The menu item is now called *Performance ▸ Low priority*.

### Upgrading from 0.3.x

Use *Update to 0.3.2…* in the tray menu, or replace `WebDavSync.exe` in the same folder.

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
