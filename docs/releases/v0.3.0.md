**Updates in one click.** WebDavSync now tells you when a new version is out and installs it for you.

### New

- **Check for updates**: tray menu *Updates ▸ Check for updates now…* shows what is new and offers
  *Install and restart*. The download is verified against the published SHA-256 checksum before anything is
  replaced; settings, passwords and the sync state are kept.
- **Automatic check**: daily by default; *Updates ▸ Check automatically* — every day, every week, every month or
  never. Each new version is announced once, and the menu shows *Update to X…* until you install it.
- **Version and release date** at the top of the tray menu and in the *Updates* menu.

### Upgrading from 0.2.x

Exit the running app, replace `WebDavSync.exe`, start it again. From this version on, updates install themselves.

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
