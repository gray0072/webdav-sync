**Cloud changes within a minute.** With Mail.ru Cloud, WebDavSync now reads the whole cloud in one request and
notices changes made in the cloud within about a minute instead of up to 15 minutes.

### New

- **Fast cloud reads (Mail.ru)**: the whole cloud side of a pair comes in one request of the Mail.ru API instead of
  one WebDAV request per folder — on a test cloud with 10 000 files in 200 folders, 1.3 s instead of 41 s. Uploads,
  downloads, moves and deletes still go over WebDAV as before.
- **Cloud change check**: every minute one small request asks the cloud whether anything changed in the synced folder;
  if so, a sync starts right away. Setting `remoteCheckInterval` (default `1m`, `0` = off).
- **Needs an app password with full access**: create the Mail.ru app password with *Mail, Cloud and Calendar*
  access (the setup wizard links to the page). With a WebDAV-only app password everything works as before, just
  slower; the log says why the fast mode is not used. Setting `useMailRuApi=false` turns it off.
- **`wds crawl <pair> [--compare]`**: reads the cloud side as a sync does, without changing anything; with
  `--compare` also folder by folder over WebDAV, and shows any difference between the two.

### Safety

A folder's listing from the Mail.ru API is used only when it is verifiably complete; anything unexpected (an unknown
answer, a login problem, shared or mounted folders) falls back to the WebDAV listing, so a change on Mail.ru's side
can cost speed, never data.

### Upgrading from 0.3.x

Use *Update to 0.4.0…* in the tray menu, or replace `WebDavSync.exe` in the same folder. To use the fast mode,
create an app password with full access and enter it with *Set password…* (or `wds secret set <pair>`).

The SHA-256 checksum of the archive is in the `.sha256` file next to it.
